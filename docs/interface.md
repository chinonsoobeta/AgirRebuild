# Agir interface

**Direction.** Cool, light and quiet: white and slate with one steel-blue accent; BC Sans for everything, deal names included; a top bar, the five steps (Documents → Review → Run → Decision → Reports) as a path across the top of a deal, and a home that lists deals with their next step. Built for a developer doing a few deals a year: roomy, guided, plain words up front, finance terms one click away. Light and dark themes. The accepted boards and their design system (`agir.css`) are the reference; `apps/web/src/styles/base.css` is its port.

**Tokens** (on `:root`, redefined under `:root[data-theme="dark"]`): `--bg`, `--surface`, `--surface-2`, `--line`, `--line-2`, `--ink`, `--ink-2`, `--ink-3`, `--accent`, `--accent-ink`, `--accent-soft`, `--accent-line`, `--pass`, `--pass-soft`, `--review`, `--review-soft`, `--stop`, `--stop-soft`, `--shadow`, `--shadow-lift`, `--knob`, `--backdrop`, `--font` (BC Sans) and `--mono` (system monospace, for hashes and quoted source lines only). Never write a literal colour outside these definitions. Numbers use `.num` (BC Sans, tabular lining figures).

**Where things go.**
- Styles: `src/styles.css` only imports. `styles/base.css` is the shared design system (change it only when a card says so); each area has `styles/<area>.css`. The old "Ink & Signal" classes and token names are gone (`legacy.css` was deleted); use the design's classes.
- Reduced motion: under `prefers-reduced-motion: reduce`, `base.css` turns off every animation and transition (the spinner stops turning, the switch stops sliding).
- Skip link: the signed-in shell starts with a "Skip to the main content" link, shown only when focused, that moves focus to `<main id="main-content">`.
- Strings: every visible string goes through `t()` in English and French. An area's new strings live in `src/strings/<area>.ts` (`en`, and `fr` typed with `FrenchOf<typeof en>` so it has exactly the same keys); `i18n.tsx` spreads them into `EN` and `FR`, last, so a key defined twice or a missing French string is a type error. Existing keys stay in `i18n.tsx`.
- Components: `components/kit.tsx` holds the design's building blocks (`Tag`, `Notice`, `Figures`/`Figure`, `Seg`, `Switch`, `ChoiceCards`, `ThemeToggle`); `components/ui.tsx` holds session, shell and deal pieces (`StatusTag`, `VerdictBadge` and `Banner` render as the design's tag and notice). Prefer route-local components.
- Areas: `shell`, `deals`, `newdeal`, `quickstart`, `documents`, `review`, `run`, `decision`, `reports`, `explore`, `audit`, `compare`, `settings`, `auth`, `landing`, `agirreview`.

**Wording.** Natural sentences in sentence case everywhere, headings, buttons and table headers included. No eyebrow text: no small uppercase or letter-spaced labels, no `text-transform: uppercase`. A status is a tag plus a sentence saying what is true and what comes next. A button says what will happen. Plain word first, finance term reachable (`Glossary`, `plainTerm`). French is natural Canadian French with its typography (a non-breaking space before `%`, `:` and `$`). `test/ui-wording.test.ts` fails on any word of four or more capitals that is not a listed real acronym.

**Theme.** `src/theme.ts`: the preference is `"light" | "dark" | "system"`, stored on the device under `agir.theme` (default light; storage errors fall back quietly). `"system"` follows `prefers-color-scheme` live. The resolved theme is written to `document.documentElement.dataset.theme`, which switches the tokens. A small script in `index.html` applies the stored preference before first paint with the same rules; `<meta name="color-scheme" content="light dark">` lets native controls follow. `useTheme()` returns `{ pref, theme, setPref }`; `ThemeToggle` switches between light and dark.
