# Third-party material

## BC Sans

- **Files:** `apps/web/public/fonts/bc-sans/` — `BCSans-Regular.woff2`, `BCSans-Italic.woff2`, `BCSans-Bold.woff2`, `BCSans-BoldItalic.woff2`, `BCSans-Light.woff2`, `BCSans-LightItalic.woff2` and `LICENSE`.
- **Where they came from:** copied unchanged from `~/agirprofinance/public/fonts/bc-sans/`, an earlier project of the same owner.
- **Upstream project:** BC Sans, by the Government of British Columbia, <https://github.com/bcgov/bc-sans>.
- **Licence, as found:** the `LICENSE` file shipped with this copy is the Apache License, Version 2.0. The upstream project states that the fonts are licensed under the SIL Open Font License, Version 1.1. Both are recorded here and the `LICENSE` file is kept next to the fonts.
- **Use:** the only typeface of the web app, declared with `@font-face` in `apps/web/src/styles/base.css` (weights 300, 400 and 700, normal and italic).
