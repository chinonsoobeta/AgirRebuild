# Production counts: privacy notice

**DRAFT — for the owner and legal review.** Not yet a published notice.

## English

To learn how Agir works on real deals, Agir keeps a small set of counts for each deal, visible only to the workspace owner: the number of documents uploaded, by file type (PDF, Excel, CSV, Word, text) and by the role set on them (deal source, evidence, context); the number of documents from which no figures were read; the number of figures read from the documents; the number of figures a person confirmed from a suggestion (a model suggestion, a remembered label or an AI reading); the number of figures a person typed; the number of person actions (approvals, rejections, changes, entries, labels, conflict choices and default acceptances) before the deal's first run; the time of the first upload and of the first run, and the minutes between them. These counts are numbers and times only. No document content, file name, value, label or field name is stored with them.

## Français

Pour comprendre comment Agir fonctionne sur de vrais projets, Agir conserve pour chaque projet un petit ensemble de comptages, visibles seulement par le propriétaire de l'espace : le nombre de documents déposés, par type de fichier (PDF, Excel, CSV, Word, texte) et par rôle attribué (source du projet, pièce justificative, contexte); le nombre de documents dont aucun chiffre n'a été lu; le nombre de chiffres lus dans les documents; le nombre de chiffres qu'une personne a confirmés à partir d'une suggestion (suggestion d'un modèle, libellé mémorisé ou lecture par IA); le nombre de chiffres saisis par une personne; le nombre d'actions d'une personne (approbations, rejets, modifications, saisies, libellés, choix entre valeurs divergentes et acceptations de valeurs par défaut) avant la première analyse du projet; l'heure du premier dépôt et de la première analyse, et les minutes qui les séparent. Ces comptages ne sont que des nombres et des heures. Aucun contenu de document, nom de fichier, valeur, libellé ni nom de champ n'est conservé avec eux.
